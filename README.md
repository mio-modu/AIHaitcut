# 루메인 헤어 (Lumain Hair)

미용실 응대 도구 — 손님 얼굴 사진에 **그 미용실이 실제로 시술한 스타일**을 미리 얹어 보여주는 웹앱.

> "이렇게 됩니다"가 아니라 **"이런 방향이에요"**를 함께 보는 도구.
> 모든 결과물은 워터마크가 박힌 **예상 이미지**로 규정됩니다.

---

## 지금 바로 실행하기

### 방법 A — 카메라까지 쓰려면 (권장)
1. `실행하기.bat` **더블클릭**
2. 브라우저가 `http://localhost:8777` 로 열립니다
3. 창을 닫으면 서버 종료

> Python 또는 Node가 있어야 합니다. 카메라(getUserMedia)는 보안 규칙상 `localhost` 또는 `https`에서만 켜집니다.

### 방법 B — 그냥 보기만 (설치 없이)
- `index.html` 을 더블클릭
- 이 경우 **카메라는 안 켜지고, "사진 업로드"만** 됩니다 (흐름 확인은 전부 가능)

## 실제 Gemini 켜기 (지금도 가능)

1. 우측 상단 **⚙ 설정** 클릭
2. **Gemini API 키** 입력 (Google AI Studio에서 발급)
3. 모델 기본값은 `gemini-3.1-flash-lite-image` (나노바나나 2 라이트, 이미지당 $0.0336).
   설정에서 `gemini-3.1-flash-image`($0.067, 품질 우선) 등으로 바꿀 수 있습니다.
4. 결과 배경(누끼)은 기본 **스튜디오 라이트 그레이**. 순백 누끼 / 원본 유지도 선택 가능
5. **견본 모델 얼굴 가리기**(기본 켜짐) — 레퍼런스 사진의 얼굴을 지워서 전송합니다.
   끄면 결과에 견본 모델 얼굴이 나올 수 있으니, 직접 올린 카드에서 마스크가 머리를
   가리는 경우에만 끄세요. 좌표는 `generate.js` 의 `FACE_BOX` 에서 조정합니다.
6. **피부 보정**은 조명 얼룩·번들거림만 아주 약하게. 잡티 제거·미백·주름 완화·갸름·동안
   효과는 전부 금지로 지시됩니다. **자세 교정은 기본 해제** — 얼굴 각도가 바뀌면 딴사람이 됩니다.
7. 결과는 **자동으로 3:4 세로컷으로 통일**됩니다 (배경 "원본 유지" 제외).
   4컷을 나란히 비교할 때 비율·구도가 어긋나지 않게 하기 위함 — 아래 "결과물 표준화" 참고.
8. 저장하면 홈의 엔진 상태가 **ON(Gemini 실연동)** 으로 바뀜

- 키가 없으면 자동으로 **데모 미리보기**로 동작합니다 (흐름 시연용).
- 생성 실패 시 데모로 자동 fallback 하고, **크레딧은 차감되지 않습니다.**

## 화면 구조 — 한 화면 3단 (태블릿 가로)

화면 넘김 없이 한 화면에서 촬영→선택→생성→확인이 다 일어납니다.

```
┌ LUMAIN HAIR ─────────────────  스타일 관리 · 이력 · 설정 ┐
│                                                          │
│  [ 손님 원본 ]    [ 헤어 라인 메뉴 ]    [ AI 예상 이미지 ] │
│   촬영/갤러리       스타일 실루엣          생성 로딩(경과s)   │
│   → 얼굴 사진       2~4개 선택            → 결과 + 예상바   │
│                    [미리보기 생성]        + 확인 체크·확정  │
│                                                          │
└ 개인정보 동의 · 사진 자동 삭제 ──────────────────────────┘
```

- **왼쪽:** 손님 원본. 촬영 직전 **개인정보 동의 모달**(건너뛰기 불가, 미성년자 보호자 동의).
- **가운데:** 스타일 카드 메뉴. 실제 모델컷 **정면 사진**이 썸네일이고, 좌하단 버튼으로 **측면**으로 전환됩니다. 사진이 없는 카드만 헤어 라인 실루엣으로 표시.
- **오른쪽:** AI 결과. 생성 로딩(경과 시간)이 이 자리에 뜨고, 결과 하단에 **"AI 예상 이미지" 반투명 바가 픽셀에 굽혀넣어집니다.** "예상 이미지 이해" 체크 후 확정.

디자인: 도시적 **미드나잇 크롬**(그래파이트 + 일렉트릭 블루 + 크롬 화이트), 에디토리얼(헤어라인 보더·serif 워드마크·모노 라벨·직각).

원장은 **스타일 카드**에 자기 시술컷을 등록해 쌓습니다. (매장별 격리 저장)

## 결과물 표준화 — 4컷을 나란히 비교하려면

손님에게 여러 스타일을 동시에 보여주는 도구라, **컷마다 배경·줌·비율이 다르면 비교 자체가
안 됩니다.** 그래서 결과물을 세 겹으로 통일합니다.

| 겹 | 무엇을 | 어디서 |
|---|---|---|
| ① 프롬프트 — 배경·구도 | 항상 **같은 라이트그레이 스튜디오 배경**, 머리&어깨 크롭, 중앙 정렬, 동일 줌, 3:4 세로, 무채색 상의(목선이 헤어를 가리지 않게), 검은 여백·레터박스 금지 | `backgroundDirectives()` |
| ② 프롬프트 — 헤어라인 | 이마로 이어지는 **부드러운 그라데이션과 잔머리**. 얹힌 느낌·붕 뜬 헤어라인 금지, 손님 원래 이마 높이·헤어라인 위치 존중 | `buildPrompt()` |
| ③ 후처리 — 프레임 확정 | 결과를 **900×1200(3:4) 캔버스에 cover·상단 정렬**로 강제 정규화. 좌우/상하 검은 여백을 잘라내고, 자투리는 스튜디오 그레이(`#d7dbe0`)로 채움 | `normalizePortrait()` |

③이 핵심입니다. **프롬프트에 의존하지 않는 결정적 후처리**라, 모델이 지시를 어기고
정사각/가로로 뱉거나 검은 띠를 넣어도 결과는 무조건 3:4로 통일됩니다.
머리는 상단에 있으므로 잘려나가는 쪽은 항상 어깨 아래입니다.

> 배경 설정이 **`keep`(원본 유지)** 일 때는 원본 구도를 지키는 게 목적이므로 ③을 건너뜁니다.

표시 레이어(`css/styles.css`)의 `.stage-img`·필름스트립 레터박스 배경도 검정이 아닌
같은 스튜디오 그레이라, 남는 여백이 생겨도 배경과 이어져 보입니다.

### 생성 파이프라인

```
손님 얼굴 사진
 → blurReferenceFace()    견본 모델 얼굴 가리기 (기본 ON)
 → buildPrompt()          정체성 보존 + 스타일 + 헤어라인 + 배경/구도 지시
 → callGemini()           정면(_1)·측면(_2) 레퍼런스 2장 첨부해 요청
 → faceSimilarityCheck()  자리만 마련 (2단계 강화)
 → normalizePortrait()    3:4 통일 + 검은 여백 제거
 → bakeWatermark()        "AI 예상 이미지" 픽셀에 굽기
 → 결과 (실패 시 데모 fallback, 크레딧 미차감)
```

## 2단계로 넘어갈 때 (백엔드 + 키 숨기기)

바꿔야 할 곳은 **딱 한 군데**입니다.

- `js/generate.js` 의 `callGemini()` 내부를
  브라우저에서 Gemini를 직접 부르는 대신,
  자기 서버 엔드포인트(예: `POST /api/generate`) 를 부르도록 교체.
- 서버가 키를 보관하고 Gemini를 호출 → 키가 브라우저에서 사라짐.
- `js/data.js`(스타일 카드/크레딧)도 localStorage → 서버 DB로 교체하면
  매장별 계정·다기기 동기화·파기 스케줄러가 실제로 동작.

흐름·UI·워터마크·동의는 그대로 재사용됩니다.

### 스타일 카탈로그 (현재 남성 9종)

투블럭 다운펌 · 가르마펌 · 리프컷 · 애즈펌 · 크롭컷 · 쉼표머리 · 슬릭백 · 히피펌 · 숏히피펌

스타일 메뉴는 **3×3 그리드**(PC 3열, 620px 이하 2열)라 9종이 딱 떨어집니다.
카탈로그를 늘리면 3의 배수로 맞춰야 마지막 줄이 비지 않습니다.


`js/data.js` 의 `STYLE_CARDS` 배열에 객체만 추가하면 늘어납니다.

| 필드 | 설명 |
|---|---|
| `front_image` / `side_image` | 정면·측면 모델컷. **둘 다 Gemini 요청에 첨부**되어 옆·뒤 길이까지 참고됩니다 |
| `tags` | `length` / `perm` / `difficulty` — 카드에 표시 + 프롬프트에 포함 |
| `prompt_params` | `cut` / `top` / `finish` / `keywords` — **AI 지시문 본문**. 여기가 재현도를 좌우합니다 |
| `gender` | `male` / `female`. 스튜디오 메뉴는 현재 `male` 만 노출 (`app.js` `listCards({gender:'male'})`) |

카드 정렬은 **성격이 같은 것끼리 한 줄**입니다 (`STYLE_CARDS` 배열 순서 = 화면 순서).
1줄 컷·정돈 / 2줄 앞머리 연출 / 3줄 전체 컬·볼륨. 카드를 추가하면 해당 줄에 넣으세요.

#### 모델컷 넣는 법

WebP, **768×1024(3:4)**, 품질 82 기준 장당 20~48KB. 현재 18장 합계 **540KB**.

```bash
# 아래 10% 를 잘라 우하단 생성 워터마크를 제거하고 3:4 로 다시 맞춘다.
# (비율 축소가 아니라 크롭이라 얼굴이 상대적으로 커진다)
magick 원본.png -crop 810x1080+43+0 +repage -resize 768x1024 -quality 82 public/images/5_1.webp
```

> AI 생성 모델컷은 우하단에 워터마크가 찍혀 나옵니다. 그대로 두면 카드에도 보이고,
> **레퍼런스로 Gemini 에 전송되어 결과에까지 번질 수 있으므로** 반드시 잘라내세요.

#### 모델컷 배경 정리 (`tools/clean-model-bg.mjs`)

배경에 흰 패널·밝은 얼룩이 섞여 있으면 카드가 지저분해 보이고, 그 요소가
레퍼런스를 통해 결과컷에 번질 수 있습니다. 인물·헤어·구도는 그대로 두고
**배경만 균일한 라이트그레이로** 바꾸는 일괄 도구입니다.

```bash
node tools/clean-model-bg.mjs --dry-run              # 대상만 확인 (호출 없음)
node tools/clean-model-bg.mjs --key <KEY> --only 5_1 # 1장만 시험
node tools/clean-model-bg.mjs --key <KEY>            # 18장 전부
```

- 장당 Gemini 크레딧 1회 소모 — **`--only` 로 한 장 확인한 뒤** 전체를 도세요.
- 원본은 `_original_images/before-bg/` 에 자동 백업(최초 1회). 되돌리려면 덮어쓰기.
- 재생성본에 워터마크가 다시 찍히므로, 받은 뒤 자동으로 크롭·3:4·768×1024 정규화합니다.

PNG 원본은 `_original_images/` 에 보관합니다 (`.gitignore` 처리되어 배포에 포함되지 않음).

내장 카탈로그는 **읽기 전용**입니다. 원장이 고치려면 "스타일 관리 → 카드 선택 →
복제해서 편집" 으로 커스텀 사본을 만들며, 사본은 정면·측면·프롬프트를 그대로 물려받습니다.
